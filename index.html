AI quality control for battery electrode microstructures

A 48-hour build for the Polaron Materials Manufacturing track. Sentinel classifies scanning electron microscope images of battery electrodes and explains each decision with cited, traceable evidence. View source on GitHub

Engineering the explainer99 tests · 16/16 self-test

  • Every number has an ID. An evidence builder assigns a fact ID to each measurement, so the model can only cite numbers that exist.
  • Code validates; the model never grades itself. A validator checks numbers, region IDs, exact quotes and the predicted class before anything ships.
  • A one-way critic. An LLM grounding critic can block an explanation but can never pass one that the code validator rejected.
  • Bounded retries. Two retries with oscillation detection, then a deterministic template, so a failure costs seconds rather than an endless loop.
  • Tested in both directions. A seeded-defect self-test confirms the checker catches 16 of 16 planted errors, backed by 99 unit tests.

Fast & Light

Low-rank adaptation for medical imaging

Adapting a segmentation model to every new anatomy is slow and expensive. With a team of six at the Macao Science Centre's Youth Science and Technology Village, we fine-tuned MedSAM2, a SAM2-based medical foundation model, using LoRA on a single A100 GPU, so the method stays practical for smaller hospitals.

Only the low-rank adapters are trained; the foundation model's weights stay frozen.

MethodChest X-ray

  • Dual-prompt fusion. Automated wide and central bounding boxes are fused as prompts, handling anatomical challenges such as the heart obscuring the lung fields.
  • Preprocessing. Cropping, resizing and CLAHE contrast enhancement standardise X-rays from varied sources.
  • Efficiency. 0.969 Dice in under 72 minutes of training, cutting training time and cost by more than 90% against traditional architectures.
